Prompt

I'm applying for a {{ Role }} position at this company: {{ CompanyWebsite }}      

`jd-keywords.yaml` contains all the important keywords, phrases and responsibilities, this company is looking for.

Purpose:
I want to know exactly which keywords, phrases, and responsibilities are absent in my resume, so that, I can put them in my resume, to increase my chances to pass the ATS filter.

Instructions:

Create a downloadable `missing-keywords.yaml` file, that contains all the keywords, phrases, and responsibilities that are not present in my `resume.yaml` file.

Rules for file creation:

1. Use `jd-keywords.yaml` file as actual ATS filter.
2. A keyword, phrase, or responsibility is considered present only if it appears explicitly in `resume.yaml` file. Do not infer synonyms, abbreviations, or equivalent technologies.
3. Do not duplicate keywords, phrases or responsibilities. Preserve abbreviations exactly as written.
4. Keep the format for `missing-keywords.yaml` file, like this:

```yaml
keywords_not_present:
- keyword 1
- keyword 2
...

phrases_not_present:
- phrase 1
- phrase 2
...

responsibilities_not_present:
- responsibility 1
- responsibility 2
...


```
