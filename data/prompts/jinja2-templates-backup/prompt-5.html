Prompt

I'm applying for a {{ Role }} position at this company: {{ CompanyWebsite }}      

`missing-keywords.yaml` contains some important keywords, phrases and responsibilities from JD, that are currently absent in my resume.

Purpose:
To add keywords, phrases and responsibilities from `missing-keywords.yaml`, into my resume, to increase ATS score.

Instructions:

1. Treat `my-skills.yaml` file, as my knowledge bank.
2. Use contents from `missing-keywords.yaml`, in generated output, to perform a transformation on resume-correction.yaml
3. If keywords, phrases or responsibilities inside `missing-keywords.yaml`, does not align with `my-skills.yaml` in any way, then leave it.
4. Output the complete transformed file as downloadable `corrected-resume.yaml`. Never truncate, summarize, omit sections, or use `...`.

Transformation rules:

1. Modify only texts inside <s>...</s> tags, in file `resume-correction.yaml`.
2. If text has been modified inside <s> tags, then only, remove these <s> tags, never remove it's content.
3. Each keyword, phrase or responsibilty from `missing-keywords.yaml` should be used at most once unless necessary for natural language.
4. Optimize each rewritten keyword or phrase or responsibility or sentence to maximize ATS keyword relevance while preserving factual accuracy, readability, and natural language.
5. Always follow this structure for generated output: Problem → Solution → Impact.
6. Prefer quantified achievements using numbers, percentages, durations, counts, latency, throughput, cost savings, deployment frequency, or scale.
7. Use only the keywords that naturally fit the rewritten sentence. Do not force every keyword into every modification.
8. Preserve the entire file exactly: structure, ordering, indentation, arrays, IDs, punctuation, spacing, and all unchanged content.
9. Never add, delete, rename, reorder, merge, split, abbreviate, paraphrase, or regenerate content outside <s> tags. Copy unchanged lines verbatim from the source file.
10. Never fabricate experience, responsibilities, technologies, projects, certifications, employers, metrics, or achievements which are not in "my-skills.yaml"
11. Preserve valid YAML syntax.
